# Проверка интерфейса Kairema

## 18 августа 2026 года — OpenRouter-пересборка

После обновления live-health проверки визуально подтверждены все пять неизменно отображаемых карточек: **Kairema Ultra (Gemma 4)**, **Kairema Code (North)**, **Kairema Long-Context (Dots3)**, **Kairema Express (GPT-OSS)** и **Kairema Auto-Router**. На момент проверки каждая карточка показала статус **«Готов»**.

Интерфейс остаётся русскоязычным и тёмным; sidebar, выпадающий выбор модели, настройки, поиск истории и поле сообщения видимы. Ключ OpenRouter в UI не раскрывается: показывается только пояснение «Ключ OpenRouter — только на сервере».
