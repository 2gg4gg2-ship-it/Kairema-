## Проверка контролируемого fallback

Для роли «Смекалистый» primary-кандидат в отдельном изолированном процессе был намеренно заменён несуществующим идентификатором. Результат: первая попытка получила HTTP 404, две последующие попытки были временно ограничены HTTP 429, а четвёртая разрешённая попытка ответила успешно. В итоговом результате `fallbackUsed` имеет значение `true`; наружу возвращены только фактически использованный провайдер и название модели, без состава цепи.
